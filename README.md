# GLÄDIA Café — موقع تجريبي / Concept Prototype

**كافيه غلاديا — المحمدية، جدة، المملكة العربية السعودية**
Concept website prototype presented by **Servlexy**.

> نموذج أولي للعرض فقط. جميع عناصر القائمة والأسعار وبيانات التواصل هي **محتوى توضيحي**
> (placeholder) وليست بيانات GLÄDIA الفعلية. لا يوجد ربط بدفع إلكتروني أو حجز فعلي.
>
> A front-end sales prototype. All menu items, prices and contact details are
> **placeholders for demonstration only**. No backend, payments or live booking.

## التشغيل / Running it

الموقع ملفات ثابتة بالكامل — يكفي فتح `index.html` مباشرة، أو تشغيله عبر XAMPP:

```bash
# XAMPP: ضع المجلد في C:\xampp\htdocs\gladia_cafe ثم افتح
http://localhost/gladia_cafe/
```

أو عبر أي خادم ثابت:

```bash
npx serve .
```

> لا يحتاج الموقع إلى اتصال بالإنترنت: الخطوط والصور كلها مستضافة محليًا.

## البنية / Structure

```
gladia_cafe/
├── index.html                 # الصفحة كاملة (عربية RTL افتراضيًا + إنجليزية)
├── style.css                  # نظام التصميم الكامل
├── fonts.css                  # @font-face للخطوط المحلية
├── main.js                    # التفاعلات + تبديل اللغة
├── *.woff2                    # Cormorant Garamond · Jost · Tajawal (29 ملف)
├── *.jpg                      # 56 صورة فوتوغرافية محسّنة
├── fetch-images.js            # تنزيل الصور من Unsplash
├── fetch-fonts.js             # تنزيل الخطوط من Google Fonts
├── extract-ids.js             # استخراج خريطة الصور
├── optimize-images.js         # إعادة ضغط الصور
├── prune-fonts.js             # حذف الخطوط غير المستخدمة
├── build-gallery.js           # توليد شبكة المعرض
└── image-ids.json             # خريطة معرّفات الصور
```

7. **زورونا** — العنوان، الموقع، ساعات العمل، معاينة الخريطة

9. **تذييل** — روابط وهوية العلامة

## المزايا التفاعلية / Interactions

- **تبديل اللغة** (ع / EN) مع قلب كامل للتخطيط RTL<LTR وحفظ الاختيار
- **فلترة القائمة** بفئات مع حركة انتقال
- **معرض صور (Lightbox)** مع أسهم ولوحة المفاتيح والسحب باللمس
- **قائمة جوال** بملء الشاشة بحركة متدرجة
- **كشف تدريجي** عند التمرير (IntersectionObserver)
- **شريط تقدّم القراءة** وتفعيل رابط القسم الحالي
- **حوارات تواصل** مع نسخ المعرّف
- دعم `prefers-reduced-motion`، تصميم طباعي، ودلالات وصول كاملة (ARIA).

## ملاحظات فنية / Technical notes

- **بلا أي إطار عمل** — HTML + CSS + JavaScript فقط، بدون تبعيات.
- **بلا خدمة خارجية** — لا خطوط أو صور من CDN، فيعمل الموقع دون إنترنت.
- **وضع المعاينة الثابتة** — أضف `?static=1` إلى الرابط لتجميد كل الحركات
  (مفيد لالتقاط لقطات الشاشة).
- **دعم لوحة المفاتيح** — `Esc` لإغلاق النوافذ، والأسهم للتنقل في المعرض.
- الصور فوتوغرافية احترافية من [Unsplash](https://unsplash.com) — يُنصح باستبدالها
  بصور GLÄDIA الحقيقية قبل الإطلاق.
